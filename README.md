# 📝 Clean Todo List App

A clean, responsive, and modern Todo List web application built using native web technologies. This project highlights efficient structural layout using CSS Grid, object-oriented state management, and real-time DOM rendering loops using JavaScript.

## 🚀 Live Demo
- **Live URL:** [View Project Live](https://poorvisha03.github.io/Todo-List/)

## ✨ Key Features
- **Modern Grid Interface:** Leverages `CSS Grid` to create perfectly aligned task layouts across varying component sizes.
- **Dynamic Task Addition:** Submits text payloads and tracking metadata synchronously.
- **Interactive Deletion:** Instantly splices selected data elements out of the tracking collection and refreshes the application UI window safely.
- **Input Validation:** Restricts submission workflows if input structures are empty, preventing visual grid fragmentation.

## 🛠️ Built With
- **HTML5:** Semantic architecture (`<input>`, `<button>`, `<script>`).
- **CSS3:** Advanced Grid layouts (`grid-template-columns`), focus element glow mapping, interactive active states, and custom typography tracking.
- **JavaScript (ES6+):** Arrow functions, array looping metrics (`forEach`), destructuring statements (`const { name, dueDate } = todoObject`), and standard event registration.
